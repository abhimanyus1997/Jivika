Jivika Clipper

Send any job to Jivika in one click.

Some job sites, including Naukri and at times LinkedIn, block server imports. Jivika Clipper is a small browser extension that reads the job you are already viewing and opens it in Jivika, ready for a match, ATS check, cover letter or interview prep.

Download Jivika Clipper Use the bookmarklet

Version 0.1.0 for Chrome, Edge and Brave. A Chrome Web Store listing is planned.

What it does

When you click the Jivika button on a job page, the Clipper reads the title, company, location, experience, salary and description, shows you a preview, and opens the Jivika page you choose with the job description filled in.

Privacy

It reads only the current tab, and only when you click. It sends nothing to our servers: the job travels to the app in the URL fragment, which browsers never send to a server. Each clip opens Jivika in a new tab. It has no background access to your browsing, no analytics and no remote code.

Install on Chrome, Edge or Brave

  1. 1

    Download and unzip

    Download jivika-clipper.zip and extract it to a folder you will keep.

  2. 2

    Open the extensions page

    Go to chrome://extensions in Chrome, edge://extensions in Edge or brave://extensions in Brave.

  3. 3

    Turn on Developer mode

    Switch on Developer mode, then choose Load unpacked and select the extracted folder.

  4. 4

    Clip a job

    Pin Jivika Clipper to the toolbar, open a job posting and click the button. Choose where to send it: Match in Jivika, ATS check, Cover letter or Interview prep.

Bookmarklet

Prefer not to install an extension? Drag this link to your bookmarks bar, then click the bookmark on a job page. It sends the job to Job match.
